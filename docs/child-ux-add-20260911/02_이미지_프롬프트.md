# 에셋 추가·교체를 위한 이미지 프롬프트

## 먼저 결정할 미술 방향

기존 꿀벌은 둥근 평면 일러스트 계열이다. 기존 UI에는 아래 ‘현재 스타일 호환’ 프롬프트를 적용한다. 부드러운 3D 점토 스타일은 A23~24 등 모델 제작 실험에서 별도 기준판을 만든 후 채택한다. 모든 에셋을 점토로 바꾸면서 기존 벌만 평면으로 남기지 않는다. 1차 설계의 무광 점토 방향은 후보 미술 방향으로 유지하되, 이번 추가안은 기존 자산 호환을 우선하는 이행 경로를 구체화한다.

실행 순서: 기존 파일 재사용 가능성 확인 → 대표 3종(A01/A07/A22) 시안 → 미술 승인 → 같은 참조를 사용해 계열 제작 → 알파/접점/시각 검수 → manifest 등록. A18~21은 마을 계열 기준판을 별도로 승인한다. A23~24는 실제 3D 개발을 하기로 결정한 뒤 생성한다.

새 이미지보다 코드가 적절한 것: 버튼, 탭, 상태 배지, 진행 바, 음량 파형, 초점 링, 로딩 스피너, 기본 액션 아이콘은 CSS/SVG/기존 아이콘으로 만든다. UI 문구·언어명·학생 이름을 생성 이미지에 넣지 않는다. 에셋은 본문을 대체하지 않으며 장식이면 alt="", 의미가 있으면 화면 맥락에 맞는 번역된 대체 텍스트를 제공한다.

아래 24개는 제안이며 전부 필수 신규 생성이 아니다. 참조 파일이 있으면 생성 도구에 실제 첨부해야 한다. 프롬프트에 파일명만 적어서는 참조가 전달되지 않는다. 학생 사진을 참조로 쓰지 않는다. 인물은 허구이며 특정 국적의 외모·의상을 고정하지 않는다.

## 공통 제작·납품 기준

- 아래 해상도는 요청값이다. 도구가 지원하는 가장 가까운 비율/크기로 생성한 뒤 과도한 크롭 없이 납품 규격을 맞춘다.
- 단일 오브젝트는 완전한 실루엣과 최소 10% 외곽 여백. 투명 출력은 실제 alpha 채널을 검사한다. 체크무늬가 그림에 그려져 있으면 반려한다.
- 투명 배경이 불가능하면 균일한 배경으로 받은 뒤 별도 후처리·검수한다. 검은 줄무늬와 눈을 배경으로 오인해 지우지 않는다.
- 글자·워터마크·서비스 로고·국기·숫자는 금지(학습 내용상 별도 검수한 경우 제외). 시트 한 장에 여러 아이콘을 생성해 대충 자르지 않는다.
- 원본 PNG와 최적화 WebP/PNG를 보존한다. 목표: 작은 캐릭터 전달본 512px/150KB 이하, 장면 1280px/300KB 이하부터 측정. 품질 손상 시 강제 통과하지 말고 예산을 재검토한다.
- manifest에는 id/file/version/hash/sourcePrompt/reference/size/alphaBounds/anchor/licenseReview/approved를 기록한다. AI 생성 여부와 사용 도구/약관 확인일을 남긴다. 배경 그림자와 접지 그림자의 중복 여부를 점검한다.
- 검수 화면: 흰색·크림·어두운 배경, 96/160/320px, 큰 글씨 UI, 모바일 크롭. 손·눈·더듬이·날개 개수, 일관된 시점과 광원, 얼굴/문구 가림을 확인한다.
- 비용 실행은 기존 CLAUDE.md의 이미지 생성 모델·배치·과금 규칙을 따라야 한다. 이번 패키지는 프롬프트만 작성했으며 이미지 생성 요청을 실행하지 않았다.

## 생성 결과를 채택하는 조건

A01~06은 감정 안내용이며 자동으로 특정 아이의 감정을 판정하는 이미지로 쓰지 않는다. A11~15는 답 하나를 강요하는 감정/문화 퀴즈의 정답 이미지로 바로 등록하지 않고 교사 콘텐츠 검토를 거친다. 인물 역할과 외형을 여러 장면에서 순환해 일방적인 문화적 역할 고정을 피한다.

A16은 레스터 장식 프레임이며 접근성 경계/포커스 표시는 별도 DOM에서 구현한다. A18~21은 2.5D 그림으로, 회전 가능한 실제 3D 자산이 아니다. 접지 앵커는 생성 결과에서 측정한다. A22는 승인된 완성 합성본 후보이며 장식 슬롯을 제거/바꾸는 조합은 render plan과 manifest로 따로 처리한다.

A23~24에서 얻는 것은 모델링 참고 그림이다. 실제 3D 완성에는 Blender 등에서 mesh/UV/재질/소켓 제작, GLB export, 삼각형 수·용량·애니메이션 검증이 필요하다. 여러 시점의 일관성이 안 맞으면 모델러가 조정하거나 다시 제작해야 한다.
