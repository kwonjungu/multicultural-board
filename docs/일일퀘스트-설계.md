# 📋 오늘의 심부름 (일일 퀘스트) — 설계서

> 꿀벌 마을 마스터플랜의 V2.5. 앱 **전 모듈**(단어·표현·감정·소통판·그림책·
> 게임·전시장·마을)과 연동되는 일일 퀘스트로, 마을의 꿀 경제에 "학습 활동"
> 이라는 유입구를 만든다. 학생은 매일 3개의 심부름을 받고, 완료하면 마을
> 꿀을 번다 — 칭찬(교사 주도)과 달리 **학생이 스스로 벌 수 있는** 축.

## 1. 설계 원칙

1. **전 모듈 연동, 침습 최소** — 각 모듈은 `reportQuestEvent()` 한 줄만 호출
   (fire-and-forget, try/catch 격리 — 카드 작성 성공이 퀘스트 실패로
   미끄러지면 안 된다는 PadletBoard 가드레일 준수).
2. **서버 크론 없음** — 오늘의 퀘스트 3개는 `hash(날짜+이름)` 결정적 회전.
   같은 학생은 같은 날 어디서 봐도 같은 퀘스트.
3. **보상 원자화** — 수령(claim)은 일일 가드 트랜잭션 선점 → 꿀 지급 트랜잭션
   (물주기와 같은 2-노드 패턴). 3개 올클리어 보너스 "황금 이슬"은 +20🍯 + XP.
4. **교사 개입 불필요** — 학생 주도(연구대회 키워드). 교사 커스텀 미션
   (IndividualSticker.missionId 필드 기활용)은 V3 백로그.

## 2. 퀘스트 풀 (8종 — 모듈당 1개)

| id | 이벤트 | 문구 | 목표 | 보상🍯 |
|---|---|---|---|---|
| q-vocab | vocab_session | 🃏 단어 공부 한 판 끝내기 | 1 | 15 |
| q-expression | expression_review | ✍️ 표현 복습 한 판 | 1 | 15 |
| q-emotion | emotion_checkin | 💚 오늘 기분 남기기 | 1 | 10 |
| q-board | board_card | 📝 소통판에 글 쓰기 | 1 | 15 |
| q-like | gallery_like | ❤️ 친구 꿀벌 응원하기 | 1 | 10 |
| q-storybook | storybook_read | 📖 그림책 읽기 | 1 | 15 |
| q-game | game_play | 🎮 게임 한 판 놀기 | 1 | 10 |
| q-water | village_water | 💧 친구 정원에 물주기 | 1 | 10 |

- 매일 3개 노출. 회전은 결정적 해시 — 학생마다/날마다 조합이 다름.
- 올클리어 보너스: 🌟 황금 이슬 +20🍯 + XP 30 (`awardXp` — 데일리골/스트릭에도 기여).

## 3. 데이터 모델 (신규 1노드)

```
rooms/{roomCode}/quests/{clientId}/{YYYY-MM-DD} = {
  events:  { [eventType]: count },   // reportQuestEvent 가 트랜잭션 증가
  claimed: { [questId]: true },      // 개별 수령 가드
  bonus:   true                      // 올클리어 보너스 수령 가드
}
```
- clientId = 학생 이름 (stickers/cosmetics/village 와 동일 키).
- events 는 오늘의 퀘스트 여부와 무관하게 **모든 타입을 기록** (통계 재활용,
  쓰기 로직 단순화). 잠재 크기: 8타입 × 일수 — 미미.

## 5. UI

- **퀘스트 보드**: 꿀벌 마을 탭 최상단 "📋 오늘의 심부름" 카드 — 퀘스트 3줄
  (이모지+문구+진행 n/target), 완료 시 "🍯 받기" 버튼, 3개 완료 시 황금 이슬
  보너스 버튼. 문구는 한국어 하드코딩(마을 정책과 동일).
- **배지**: 칭찬판 탭줄의 "🏡 꿀벌 마을" 라벨에 미수령 보상 개수 배지(●) —
  다른 모듈에서 활동하고 돌아왔을 때 수령 유도.
