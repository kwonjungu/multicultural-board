## 항목 1. 그림책 복습 중 의견(댓글) 추가 — 질문 응답 대댓글

**요구**: 그림책을 복습(감상)하는 학생이 친구들의 응답을 보며 **복습 중에도 자기 의견을 댓글처럼 추가**할 수 있게.

**현재 동작 (근거)**
- 질문별 응답은 `StorybookResponse` 로 저장/구독. `submitResponse()` / `subscribeResponses(roomCode, q.id, cb)` (`components/StorybookRoom.tsx:1092`, `lib/storybook.ts`).
- 질문 카드는 응답을 "과일 나무(fruit)" 로 시각화하고 탭하면 해당 응답 1개만 확대(`selectedFruit`) — **읽기 전용**. 대댓글 없음.
- RTDB 스키마: `rooms/{roomCode}/storybook/responses/{questionId}/{responseId}`.

**설계**
1. **데이터 모델 추가** — 응답 하위에 댓글 서브트리:
   ```
   rooms/{roomCode}/storybook/responses/{questionId}/{responseId}/comments/{commentId}
     = { id, clientId, studentName, studentLang, text, timestamp, flagged? }
   ```
   `lib/types.ts` 에 `StorybookResponseComment` 인터페이스 신설(`CommentData` 를 축약 재사용 가능). `StorybookResponse` 에는 스키마 변경 불필요(하위 노드로만 추가).
2. **lib/storybook.ts 함수 추가**:
   - `appendResponseComment(roomCode, questionId, responseId, comment)` — `push` + fire-and-forget.
   - `subscribeResponseComments(roomCode, questionId, responseId, cb)` — 선택된 응답에만 구독(전체 구독 금지, 첫 fire 시딩).
3. **UI (`QuestionCard` 확대 뷰, `StorybookRoom.tsx` 내 fruit 상세)**:
   - 확대된 응답 아래에 댓글 리스트 + 입력창(텍스트, 200자 제한). `MicButton` 재사용 가능.
   - 전송 전 `checkSafety(text)` (`lib/chatSafety.ts`) 로 클라이언트 사전 안전검사. distress → `raiseAlert(roomCode, {kind:"distress"})`, blocked → 차단 토스트.
   - 저장은 낙관적. 실패 시 `Toast` tone `error`.
   - 댓글도 **원문 + 뷰어 언어 번역 2줄 표시** (항목 5의 `ensureTranslation` 로직 재사용).
4. **적용 페이즈**: 복습 성격이므로 `phase === "after"`(감상/핫시팅) + `during` 의 응답 상세에 노출. 교사·학생 모두 열람, 학생은 작성 가능.

**엣지케이스**: 같은 응답에 동시 댓글 다수 → push key 라 충돌 없음 / 승인모드(approvalMode)와 무관(그림책은 별도 안전 레이어).

**검증**: 2개 탭(학생 A/B)에서 같은 질문 응답에 서로 댓글 → 실시간 반영, 번역 2줄, distress 문구 시 교사 배너 알림.

**공수**: 1.0일

## 항목 2. 컬럼 관리 정리 — 관리패널에서 제거 + 소통판 내 관리 + 더블클릭 삭제(경고)

**요구**: ① "관리(⚙)" 패널에서 컬럼 관리 기능을 **명확히 제거** ② 소통판(보드) 안에서 컬럼을 직접 관리(이름/색/순서/추가/삭제) ③ 교사가 컬럼 헤더를 **더블클릭하면 삭제**, 안전판으로 **경고** 표시.

**현재 동작 (근거)**
- 컬럼 관리가 **관리 모달 안**에 있음: `PadletBoard.tsx:1279–1470` ("컬럼 관리" 섹션 = 이름 input, ▲▼ 순서, 색 스와치, 🗑 삭제, "새 컬럼 추가").
- 보드에서는 컬럼 하단 "+ 추가" 버튼을 **롱프레스(600ms)** 하면 삭제 모드로 전환(`colDeleteActive`, `PadletBoard.tsx:1055–1111`). 되돌리기 스낵바 `showUndoToast` 존재(`:103`, `deleteCol` `:258`).
- 컬럼 데이터: `rooms/{roomCode}/columns/{colId} = {title,color,order}`. 관련 함수 `saveColTitle/changeColColor/deleteCol/moveCol/addColumn` 모두 이미 존재(`:246–308`).

**설계**
1. **관리 모달에서 컬럼 관리 제거** — `PadletBoard.tsx:1279–1470` 의 "컬럼 관리" + "새 컬럼 추가" 블록 삭제. `editTitle/newColTitle/newColColor` 중 관리모달 전용 사용부 정리. **단, 언어 설정 블록(:1372–1408)은 유지**(컬럼 아님).
2. **소통판 내 "컬럼 관리" 진입점 신설** — 보드 우측 끝(마지막 컬럼 뒤)에 교사 전용 **`＋ 새 컬럼`** 카드 + 각 컬럼 헤더에 교사 전용 **⚙(작게)** 를 두고, 누르면 그 컬럼용 **인라인 편집 팝오버**(이름 input, 색 스와치, ▲▼ 순서). 기존 `saveColTitle/changeColColor/moveCol/addColumn` 재사용 → 로직 신규 작성 최소.
3. **더블클릭 삭제 + 경고** — 컬럼 헤더(`PadletBoard.tsx:986` 헤더 div)에 `onDoubleClick`(교사만) 추가:
   - 1차: 헤더가 붉게 바뀌고 `window.confirm` 대신 **인라인 경고 배너** ("이 컬럼과 카드 N개가 삭제됩니다. 한 번 더 눌러 확정") + `colDeleteActive=col.id` 세팅.
   - 2차 더블클릭/확정 버튼 → `deleteCol(col.id)` 실행(기존 `showUndoToast` 되돌리기 그대로 활용).
   - **안전판**: 해당 컬럼에 카드가 있으면 경고에 카드 수 표기. 카드까지 지울지/카드는 첫 컬럼으로 이동시킬지 선택 버튼 2개 제공(권장: 기본은 삭제, "카드 옮기기" 옵션).
   - 기존 롱프레스 삭제 경로는 **더블클릭으로 대체·제거**(모바일은 롱프레스 유지 가능 — 두 경로 공존 허용).

**엣지케이스**: 마지막 1개 컬럼 삭제 금지(최소 1개 보장). 학생에게는 관리 UI 전부 숨김(`isTeacher` 가드).

**검증**: 교사로 컬럼 헤더 더블클릭 → 경고 → 확정 삭제 → 스낵바 "되돌리기" 동작. 관리(⚙) 패널에 컬럼 관리 항목이 더 이상 없음.

**공수**: 1.0일

## 항목 3. 교사 허용 시 복습 중 챗봇 사용 (기본 OFF · 세션별 토글)

**요구**: 교사가 허용하면 학생이 그림책 **복습 중에도 캐릭터 챗봇**을 활용.

**현재 동작 (근거)**
- 그림책 세션: `StorybookSession { bookId, phase, currentPage, currentQuestionId, activeCharacterId, teacherClientId, startedAt }` (`lib/types.ts:231`).
- 캐릭터 챗(핫시팅)은 `after` 페이즈에서 `activeCharacterId` + `appendChatTurn/subscribeChat` 로 동작. `during`/응답 복습 중에는 챗 비활성.
- 앱 전역 튜터 챗 `TutorChat` 은 별개(항목 4).

**설계**
1. **세션 필드 추가** — `StorybookSession.allowReviewChat?: boolean` (기본 미설정=OFF). `lib/storybook.ts` 에 `setAllowReviewChat(roomCode, boolean)` 추가.
2. **교사 UI** — `SessionHeader`(`StorybookRoom.tsx:558`) 또는 `TeacherPageControls` 에 토글 스위치 "복습 중 캐릭터에게 질문 허용" 추가. 낙관적 쓰기.
3. **학생 UI** — `during`/응답 상세 화면에서 `session.allowReviewChat === true` 일 때만 "🐝 캐릭터에게 물어보기" 버튼 노출 → 기존 핫시팅 챗 컴포넌트를 모달로 재사용. 3중 안전 레이어(`checkSafety` + 서버 `enforceQuestionEnding`) 그대로 적용. 캐릭터는 `book.characters` 에서 선택(항목 4와 연동).
4. **가드레일**: 챗 응답은 반드시 질문으로 끝남(CLAUDE.md), 턴 한도(turn_limit alert) 유지.

**검증**: 교사 OFF → 학생 화면 챗 버튼 없음. 교사 ON → 버튼 노출, 실제 대화 + 안전 필터 작동.

**공수**: 0.5일

## 항목 4. 학생 1인이 여러 챗봇과 대화 (뒤로가기로 다른 챗봇 선택)

**요구**: 학생 한 명이 **여러 캐릭터 챗봇**과 대화. **뒤로가기**를 누르면 다른 챗봇을 다시 고를 수 있게.

**현재 동작 (근거)**
- 핫시팅은 `session.activeCharacterId` **단일 값**(교사가 지정)으로 전 학급이 같은 캐릭터와 대화하는 구조.
- `book.characters` 는 복수 존재(`Storybook.characters`), 하지만 학생이 개별 선택하는 UI 없음.

**설계**
1. **학생 로컬 선택으로 전환** — 핫시팅 챗을 "세션 전역 단일 캐릭터"가 아니라 **학생별 로컬 선택**으로 변경.
   - 캐릭터 선택 화면(그리드: `book.characters` 아바타 + 이름) → 캐릭터 선택 시 그 캐릭터와 챗.
   - 챗 화면 상단에 **← 뒤로** 버튼 → 캐릭터 선택 화면으로 복귀 → 다른 캐릭터 선택 가능.
2. **채팅 로그 분리** — 캐릭터별로 분리 저장:
   ```
   rooms/{roomCode}/storybook/chat/{clientId}/{characterId}/{turnId}
   ```
   `appendChatTurn/subscribeChat` 시그니처에 `characterId` 추가. (현재 단일 경로 → 캐릭터 차원 추가.)
3. **교사 지정과의 관계**: 교사가 `activeCharacterId` 를 지정하면 그 캐릭터를 기본 하이라이트하되, 학생은 뒤로가기로 자유 전환 가능(학생주도 키워드 부합).
4. 항목 3의 "복습 중 챗봇"도 이 선택 화면을 공유.

**엣지케이스**: 캐릭터 0명(구 그림책)일 때는 기본 벌 마스코트 1개로 폴백. 뒤로가기 시 현재 스트리밍 중이면 중단 처리.

**검증**: 학생이 캐릭터 A와 대화 → 뒤로 → 캐릭터 B 선택 → 각 로그 독립 유지.

**공수**: 1.0일

## 항목 5. 복습 시 원문 + 번역본을 2개 언어로 모두 표시

**요구**: 복습에서 친구 응답을 볼 때 **원문과 번역본을 모두**(2개 언어) 표시. 예: 중국 학생에게 한국어→중국어 번역만 보이지 말고 **원문도** 보이게. "소통창처럼."

**현재 동작 (근거)**
- 페이지/질문 텍스트: `bilingual(map, lang)` 이 이미 primary(뷰어 언어)+secondary(한국어) 2줄 표시(`StorybookRoom.tsx:85–99`, `BilingualText` `:968`).
- **응답(친구 글)**: `ensureTranslation(r)` 로 뷰어 언어로만 번역, `showOriginal` **토글**로 원문을 감췄다 보였다 함(`StorybookRoom.tsx:1069, 1099–1124`). → 기본은 번역만 보임.

**설계**
1. **응답 표시를 항상 2줄 고정** — fruit 상세/응답 리스트에서 다음을 **동시에** 렌더:
   - 1줄: **원문** (`r.text`, `r.studentLang` 국기 뱃지)
   - 2줄: **뷰어 언어 번역** (`ensureTranslation` 결과, 국기 뱃지)
   - `showOriginal` 토글 제거(항상 표시). 두 언어가 동일(작성자=뷰어 언어)하면 1줄만.
2. **댓글(항목 1)에도 동일 규칙** 적용 → `BilingualPair` 공용 소컴포넌트로 추출해 페이지/질문/응답/댓글 재사용.
3. 번역은 기존 `/api/storybook-translate` (배치 `texts[]`) 사용, 응답별 캐시 유지.

**엣지케이스**: 번역 실패 시 원문만 + "번역 준비중" 회색 라벨. `studentLang` 없으면 원문만.

**검증**: 중국어 학생 화면에서 한국어 작성 응답이 "🇰🇷 원문 / 🇨🇳 번역" 2줄로 항상 노출.

**공수**: 0.5일

## 항목 6. 월드마블 주사위 에셋(빈 주사위) 정리

**요구**: 소통의 게임 → 월드마블(BeeWorldMarble)에서 **주사위가 비어 보이는** 상태 수정.

**현재 동작 (근거)**
- 주사위는 **CSS 3D 큐브**로 구현(`components/games/BeeWorldMarble/DicePanel.tsx`) — 이미지 에셋이 아님. 6면을 `transform-style: preserve-3d` + `backfaceVisibility:hidden` 로 배치, 눈알(pip)은 grid 로 그림.
- 초기값 `diceA=1, diceB=1` (`lib/marbleReducer.ts:90`) 이라 값은 정상. `ActionPanel.tsx:258` 에서 `state.diceA/diceB` 전달, `compact` 사이즈 44px.
- **추정 원인**: 일부 태블릿/웹뷰에서 `preserve-3d` 미지원 또는 부모 컨테이너(`CenterCard`, overflow:hidden, perspective 상속) 문제로 큐브가 붕괴 → 흰 면만 보이고 pip 이 뒷면으로 돌아가 **빈 사각형**으로 보임. (실제 교실 태블릿에서 재현 필요.)

**설계**
1. **재현·진단** — 실제 사용 기기(태블릿 브라우저)에서 F12 없이도 확인 가능하도록, 우선 재현.
2. **견고한 대체(권장)** — 3D 큐브를 **2D 평면 주사위 면**으로 폴백/전환:
   - `Die` 컴포넌트에 "굴리는 중"이 아닐 때는 **정지 면(현재 값)의 평면 렌더**(단일 `faceBase` div + pip grid)로 표시. 굴릴 때만 짧은 회전/떨림 애니메이션(2D `rotate`+scale)로 대체 → preserve-3d 의존성 제거.

**검증**: 발음 통과 → 저장 → 성공 토스트 + "저장된 녹음" 재생. 네트워크 차단 상태에서도 학습 진행(다음 단어)은 가능.

- UI 라벨은 `lib/i18n.ts` `t(key, lang)`.

**설계**
1. **UI 라벨 = i18n 사전 유지·보강** — 게임 셸/버튼/공통 문구는 `lib/i18n.ts` 테이블에서 15언어 확보(누락 키 채움).
2. **게임 콘텐츠 = 런타임 번역 + 캐시 레이어** — `tr()` 를 대체/보강하는 훅 `useGameText(map, lang)`:
   - map 에 `lang` 있으면 그대로.
   - 없으면 **번역 API**(`/api/translate` 또는 `/api/storybook-translate` 재사용) 로 `ko`(원본 기준) → `lang` 번역, **Firebase/localStorage 캐시**(`rooms/{room}/i18nCache/{hash(ko)}/{lang}` 또는 앱 전역 캐시)에 저장 후 재사용. 반복 호출 없이 1회만.
   - **한국어 원본 100% 보장**: 모든 `LangMap` 은 `ko` 필수(누락분 점검 스크립트로 채움). 번역 소스는 항상 `ko`.
3. **영어 가짜 2줄 제거** — 게임의 2줄(langA/langB) 렌더에서 대상 언어 미보유 시 **영어 폴백을 표시하지 않고**, 위 캐시 번역으로 실제 대상 언어를 채운다. 번역 준비 전에는 원문(ko)만 노출하고 도착 시 치환. 즉 "한국어는 항상, 대상 언어는 실제 번역으로".
4. **적용 범위·우선순위** — 사용 빈도 높은 게임부터: 월드마블 타일/찬스/퀴즈(`marbleData`), 인사릴레이(`GREETINGS`), 국가맞추기/스무고개/타부 등. `tr()` 호출부를 `useGameText` 로 점진 교체.
5. **비용/성능 가드** — 번역은 방 언어 세트에 한해 프리페치(수업 시작 시 1회 배치). Groq/Gemini 429 대비 `withGroqKeyFallback` 경로 사용. 캐시 우선.

**엣지케이스**: 번역 실패 → ko 원문 유지(빈칸 금지). 문화 감수성(marble 리뷰 문서 원칙) 유지 — 자동 번역이 "우열" 뉘앙스 넣지 않도록 프롬프트 고정.

**검증**: 방 언어 = ko+th(태국어) 설정 → 월드마블/인사릴레이가 영어가 아닌 **태국어**로 표시, 한국어는 항상 노출.

**공수**: 2.0일 (레이어 + 프리페치 + 주요 게임 교체)
