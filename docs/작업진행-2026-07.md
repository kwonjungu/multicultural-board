### #12 게임 다국어 (코어 완료, 확산 진행형)
- `lib/gameI18n.tsx` 신설:
  - `useGameText(map, lang)` 훅 — map[lang] → (ko→번역 API, 메모리+localStorage 캐시 `gi18n:{lang}:{hash}`, in-flight dedupe) → ko 원문. **영어 폴백을 표시하지 않음**.
  - `<GameText map lang />` — `{tr(map, lang)}` 의 drop-in 대체 (리스트 렌더 안 훅 안전).
  - `translateGameText(ko, lang)` — 문자열 필요한 곳(TTS 등)용 async.
  - `prefetchGameTexts(maps, lang)` — 게임 마운트 시 배치 1회. 백엔드는 `/api/storybook-translate` 재사용.
- 적용 완료: **BeeWorldMarble** — `Tile.tsx`(useGameText 2개, friend==primary 면 2줄 억제), `ChanceCard.tsx`(4개), `ActionPanel.tsx`(GameText 3곳), `index.tsx`(TILES landmark + CHANCES title/body 프리페치 langA/langB).
