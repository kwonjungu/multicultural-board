## 현재 시스템 (사실관계)

- 스테이지 5: egg(0-1)→larva(2-3)→pupa(4-7)→bee(8-14)→queen(15+)
- 슬롯 4: skin(6색) / hat(4종) / pet(4종) / trophy(2종)
- 렌더 방식: **skin+hat = 사전 합성본**(25조합×4모자=100장, Gemini edit) / **pet·trophy = 런타임 오버레이**(고정 좌표)
- ⚠ 사전 합성 방식은 조합 폭발 — 모자 1종 추가 = 이미지 25장. **신규 카테고리는 전부 런타임 오버레이로** (CLAUDE.md 가드레일).

## 단계별 로드맵

### Phase 1 — 코드만 (에셋 불필요) ✅ 구현됨
- **펫 위치 선택**: `StudentCosmetics.petPos?: "right"(기본) | "left"`. CosmeticPicker에서 펫 선택 시 ◀▶ 토글. 렌더 3곳(내 꿀벌집/전시장 카드/전시 팝오버) 반영.

### Phase 2 — 스테이지 아트 v2 (파일 교체 = 코드 무수정)
같은 파일명으로 덮어쓰면 끝: `public/stickers/stage-2-larva.png`, `stage-3-pupa.png` (+원하면 egg/bee/queen).
- ⚠ 교체 시 재채색 스킨(`skins/stage-*-{색}.png`)과 모자 합성본(`stage-hats/`, `skin-hats/`)도 어긋남 → **v2는 기본+스킨 세트부터**(6색×교체 스테이지 수), 모자 합성본은 이후 배치.
- 교체 후 `node scripts/trim-stickers.mjs` → 트림본에서 head 좌표 재측정 → `anchors.json` 갱신 필수.

### Phase 3 — 신규 카테고리 (런타임 오버레이, 앵커 기반)
| 카테고리 | 슬롯 | 앵커 | 언락 | 초기 종수 |
|---|---|---|---|---|
| backdrop 배경 | 캐릭터 뒤 풀사이즈 | 불필요 | pupa+ | 4 (꽃밭/벌집/무지개/밤하늘) |
| aura 이펙트 | 캐릭터 감싸는 프레임 | 불필요 | bee+ | 3 (반짝이/하트/별가루) |
| held 소지품 | 손 위치 | anchors.json에 `handXPct/handYPct` 추가 측정 | bee+ | 3 (꿀단지/책/깃발) |
| acc 목·얼굴 | 목 위치 | `neckYPct` 추가 | pupa+ | 3 (리본목도리/안경/목걸이) |
- 데이터: `StudentCosmetics`에 `backdrop/aura/held/acc` 4필드 추가(null 허용). `stage.ts`에 `unlockedBackdrops()` 등 4함수.
- 렌더 z순서: backdrop(0) < 캐릭터(1) < held/acc(2) < pet/trophy(2) < aura(3).
- CosmeticPicker: 탭 4→8개는 과밀 → 2단 그룹("꾸미기"/"특수효과") 또는 가로 스크롤 탭.

### Phase 4 — 여왕벌 전용 커스텀
- queen 도달 시: 전용 왕관 3종(hat 확장: `crown-rose/crown-sapphire/crown-honey`), 망토(acc), 왕좌 배경(backdrop-throne), 황금 오라(aura-royal).
- 슬롯 정책: 일반 스테이지 = hat+pet+trophy+acc 중 3개까지 / queen = 전 슬롯 동시 착용 허용 → "여왕의 특권" 연출.
- `unlocked*` 함수에서 rank("queen") 게이트.

### 색 확장 (skin 6→9)
mint / red / gold 추가. 스킨은 재채색본이므로 스테이지 5장×3색=15장 생성 (+모자 합성 60장은 후순위).

## 에셋 규격 (필수)
- **1024×1024 PNG, 완전 투명 배경**, 피사체 중앙, 텍스트/워터마크 금지
